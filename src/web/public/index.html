    再生リストの最新動画リンク

    再生リストを登録すると、その最新動画のURLをコメントに差し込めます。 例：ハイライト再生リストを highlight というキーで登録すると、 {{playlist_highlight_url}} が使えるようになります。

    投稿履歴

    🛑 投稿を止める・取り消す

    未投稿のキューを消す：まだ投稿されていないジョブを削除します。実際の投稿には影響しません。
    投稿済みのコメントを削除：YouTube に実際に書き込まれたコメントを削除します。 TikTok は削除APIが無いため手動対応が必要です（対象URLを表示します）。

    今後の自動投稿を止めるには、Railway の環境変数に DRY_RUN=true を設定するか、 「アカウント連携」タブで連携を解除してください。

    除外リスト（この動画にはコメントしない）

    登録した動画には、条件に一致しても絶対にコメントしません。 待機中のジョブがあれば、登録と同時に取り消します。

    1. アカウント連携（新着検知 / YouTubeコメント投稿）

    YouTube は連携するだけで新着検知とコメント投稿ができます。TikTok は新着検知のみ API で行います。

    YouTube を連携する TikTok を連携する
    リダイレクトURI

    アプリが実際に送信している値です。開発者コンソールに一字一句そのまま登録してください。 redirect_uri エラーはこの不一致が原因です。 TikTok は Sandbox と Production で設定が別なので、 いま使っている Client Key と同じ環境に登録する必要があります。

    2. ログインセッションの登録（ピン留め / TikTokコメント用）

    なぜ必要か： YouTube・TikTok のどちらにも「コメントをピン留めする」公式APIがありません。 TikTok には自分の動画へコメントを投稿するAPIもありません。 そのため、この2つだけは自分のログイン済みブラウザと同じCookieを使って 画面を自動操作します。Cookie は暗号化して保存されます。

    取得方法：PCのブラウザで対象アカウントにログイン → Cookie エクスポート拡張機能で JSON 形式でコピー → 下に貼り付け。詳細は docs/BROWSER-SESSION.md を参照。
