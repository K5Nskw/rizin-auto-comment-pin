# 4. ピン留め用のログインCookieを登録する

## なぜ必要か

YouTube にも TikTok にも **「コメントをピン留めする」公式APIが存在しません。**
TikTok には自分の動画にコメントを投稿するAPIもありません。

そのため、この2つの操作だけは **自分がログインしているブラウザと同じ状態** を
サーバー上の Chromium で再現して、画面を自動操作します。
そのために必要なのが、ログイン状態を表す Cookie です。

| 操作 | 方法 |
|---|---|
| YouTube のコメント投稿 | 公式API（Cookie不要） |
| YouTube のピン留め | **ブラウザ自動操作（Cookie必要）** |
| TikTok のコメント投稿 | **ブラウザ自動操作（Cookie必要）** |
| TikTok のピン留め | **ブラウザ自動操作（Cookie必要）** |

> Cookie は `ENCRYPTION_KEY` を使って AES-256-GCM で暗号化してデータベースに保存されます。
> 管理画面に表示されることはありません。

---

## 4-1. Cookie を取り出す

PCのブラウザ（Chrome / Edge）で作業します。

1. **対象のアカウントでログインした状態**にする
   - YouTube: RIZINチャンネルを管理しているアカウント
   - TikTok: RIZINのTikTokアカウント
   - ※ブランドアカウントの場合、YouTubeで**そのチャンネルに切り替えた状態**にしてください
2. Cookie エクスポート系の拡張機能を入れる
   - 「**EditThisCookie**」「**Cookie-Editor**」などが定番です
3. `https://www.youtube.com` を開いた状態で拡張機能を開き、**Export**（JSON形式でコピー）
4. 同様に `https://www.tiktok.com` でも Export

コピーされるのは、こういう形の JSON です。

```json
[
  { "name": "SID", "value": "xxxx", "domain": ".youtube.com", "path": "/", "secure": true, ... },
  { "name": "HSID", "value": "xxxx", "domain": ".youtube.com", ... }
]
```

Playwright の `storageState` 形式（`{"cookies": [...], "origins": [...]}`）でも受け付けます。

## 4-2. 管理画面に登録する

1. 管理画面 → **アカウント連携** タブ
2. 「2. ログインセッションの登録」のセクションへ
3. YouTube 用の欄に貼り付けて **保存**
4. **ログイン確認** を押す（20秒ほどかかります）
   - 「ログイン済みです」と出れば成功
   - 「ログインしていません」の場合は 4-3 を確認
5. TikTok も同様に行う

## 4-3. うまくいかないとき

**「ログインしていません」と出る**

- ログインしていない状態でエクスポートした
- 必要な Cookie が含まれていない（`.youtube.com` / `.google.com` の両方、TikTokは `sessionid` が必要）
- エクスポート後に元のブラウザでログアウトした（→ Cookieが無効化されます。
  シークレットウィンドウで書き出し、ログアウトせずに閉じるのが確実です）

**ピン留めだけ失敗する**

- 「失敗時の画面を見る」ボタンでスクリーンショットを確認してください
- 「メニューに『固定』項目が見つかりませんでした」→ その動画の投稿者アカウントでログインできていません
  （ブランドアカウントの切り替え漏れが多いです）

## Cookie の有効期限について

Cookie はいずれ失効します。目安は以下ですが、確約はできません。

| サービス | 目安 |
|---|---|
| YouTube (Google) | 数ヶ月〜。パスワード変更や全端末ログアウトで即失効 |
| TikTok | 1〜2ヶ月程度 |

**失効すると通知が飛びます**（`NOTIFY_WEBHOOK_URL` を設定している場合）。
その際は同じ手順で登録し直してください。

月1回くらい、管理画面の「ログイン確認」を押して健康チェックしておくと安心です。

### すぐ切れてしまうとき

目安よりずっと早く切れる場合、原因はたいてい次のどれかです。

| 原因 | 対処 |
|---|---|
| **エクスポート元のブラウザでログアウトした** | ログアウトすると、書き出し済みの Cookie もサーバー側で無効になります。**シークレットウィンドウでログイン → Cookie を書き出す → ログアウトせずにウィンドウを閉じる**の順にしてください |
| **同じアカウントで「すべてのデバイスからログアウト」やパスワード変更をした** | 登録し直してください |
| **ブラウザ拡張で1サイトぶんしか書き出していない** | YouTube のログインは `.youtube.com` と `.google.com` にまたがります。両方を書き出して、それぞれ貼り付けてください（貼り付けは上書きではなく統合されます） |
| **長く使われないまま放置された** | Google は使われるたびに Cookie を差し替えるので、放置すると差し替えの流れから外れて拒否されます。本ツールは**4時間ごとに自動で1ページ読み込んで更新**します。手動で更新したいときは「セッションを更新」を押してください |

管理画面のダッシュボードに **最終更新** が出ます。ここが何日も前のまま止まっているときは、
更新が通っていない（＝そのうち切れる）サインです。「セッションを更新」で確かめてください。

## 使いたくない場合

ブラウザ自動操作を一切使わない運用もできます。

```
ENABLE_BROWSER_AUTOMATION=false
```

この設定では：

- YouTube: コメントの自動投稿までは行われます。ピン留めは「手動でやってください」という通知が飛びます
- TikTok: コメント文だけ生成して、「この文面で投稿・ピン留めしてください」という通知が飛びます

通知には投稿すべき文面がそのまま入っているので、コピペするだけで済みます。

さらに Railway の **Build Args** で `INSTALL_BROWSER=false` にすると、
Chromium がイメージに含まれなくなりデプロイが速く・軽くなります。

---

## セキュリティ上の注意

Cookie はアカウントへのログイン情報そのものです。

- `ENCRYPTION_KEY` を必ず設定してください（未設定だと平文で保存されます）
- `ADMIN_PASSWORD` を必ず設定してください（管理画面が誰でも開ける状態になります）
- Railway のプロジェクトを共有する相手に注意してください
- 退職者が出た場合など、必要に応じて Google の「すべてのデバイスからログアウト」で Cookie を無効化できます
