# 5. コメント文の編集

管理画面の **「コメント文の編集」** タブから、いつでも変更できます。
保存した瞬間から次の投稿に反映されます（再デプロイ不要）。

---

## 基本の考え方

テンプレートは何個でも登録できます。動画が投稿されると：

1. 有効なテンプレートのうち、**プラットフォームが一致**するものを絞り込み
2. **条件（タイトルのキーワードなど）に一致**するものを絞り込み
3. その中で **優先度が一番小さいもの** を1つ選ぶ
4. 文面が複数登録されていれば、**ランダムで1つ**選ぶ
5. `{{変数}}` と `[[ランダム]]` を展開して投稿

「どれにも一致しない」を防ぐため、条件が「すべての動画」で優先度が大きい
**デフォルトのテンプレート**を1つ残しておくことをおすすめします。

---

## 設定項目

| 項目 | 説明 |
|---|---|
| **名前** | 管理用の名前。投稿内容には影響しません |
| **対象プラットフォーム** | 両方 / YouTube（Shorts含む） / YouTube Shorts のみ / TikTok のみ |
| **優先度** | 小さいほど優先。同じ動画に複数当てはまるときの順番 |
| **使う条件** | すべての動画 / キーワードを含むとき / 正規表現に一致するとき |
| **条件の値** | キーワードはカンマ区切り（どれか1つ含まれれば一致）。大文字小文字は区別しません |
| **有効にする** | オフにすると使われなくなります（削除せず一時停止できます） |
| **コメントをピン留めする** | オフにするとコメントするだけでピン留めしません |
| **投稿までの待ち時間** | 動画公開の何秒後にコメントするか。既定30秒 |
| **コメント本文** | 複数登録するとランダムで選ばれます |

### Shorts だけに別の文面を使う

対象プラットフォームで **「YouTube Shorts のみ」** を選ぶと、そのテンプレートは Shorts にだけ使われます。

| 設定 | 適用される動画 |
|---|---|
| YouTube（Shorts含む） | YouTube の全動画（Shorts も対象） |
| YouTube Shorts のみ | Shorts だけ |

**「YouTube（Shorts含む）」は Shorts も対象に含みます。** Shorts 用を優先させたい場合は、
Shorts 用テンプレートの優先度を小さく（例: 10）、通常用を大きく（例: 100）してください。

YouTube には「Shorts かどうか」を返す API が無いため、`youtube.com/shorts/<動画ID>` に
アクセスして判定しています。判定できなかった場合、その動画は
**「YouTube Shorts のみ」のテンプレートには一致しません**（誤って Shorts 用の文面を
通常動画に付けるのを避けるため）。通常の YouTube テンプレートは従来どおり適用されます。

AutoClipMaker から届いた切り抜きは、判定を行うまでもなく Shorts として扱います。

### 条件のマッチ対象

キーワード・正規表現は、**動画のタイトルと説明文の両方**に対して判定されます。

## 使える変数

本文中に書くと、投稿時に実際の値へ置き換わります。
編集画面の変数チップをクリックすると、カーソル位置に挿入されます。

| 変数 | 展開結果の例 |
|---|---|
| `{{title}}` | `【RIZIN】試合ハイライト｜〇〇 vs 〇〇` |
| `{{url}}` | `https://www.youtube.com/watch?v=xxxxx` |
| `{{videoId}}` | `xxxxx` |
| `{{platform}}` | `youtube` または `tiktok` |
| `{{channel}}` | 連携したアカウント名 |
| `{{date}}` | `2026/07/31` |
| `{{time}}` | `21:00` |
| `{{datetime}}` | `2026/07/31 21:00` |
| `{{weekday}}` | `金` |

日時はすべて日本時間です。存在しない変数を書くと保存時にエラーになります。

## 再生リストの最新動画リンクを差し込む

「新しい動画に、最新のハイライトへのリンクを貼る」といった相互送客ができます。

### 設定

**コメント文の編集** タブの「再生リストの最新動画リンク」で登録します。

| 項目 | 説明 |
|---|---|
| **キー** | 変数名に使われます。半角英数字とアンダースコアのみ（例: `highlight`） |
| **表示名** | 管理画面での表示用（例: `ハイライト再生リスト`） |
| **再生リストID** | YouTubeの再生リストURL `...playlist?list=PLxxxxxxxx` の `list=` 以降 |
| **どれを「最新」とするか** | 下記参照 |

登録すると、使える変数がその場で表示されます:

```
{{playlist_highlight_url}}     最新動画のURL
{{playlist_highlight_title}}   最新動画のタイトル
```

**「この再生リストをテスト」** ボタンで、実際にどの動画が選ばれるか保存前に確認できます。

### 「最新」の判定方法

再生リストの運用方法によって正解が違うため、選べるようにしています。

| 設定 | 選ばれる動画 |
|---|---|
| **公開日が最も新しい動画**（既定） | 再生リスト内で最も新しく公開された動画 |
| **再生リストの先頭** | 新しい動画を手動で先頭に追加している場合 |
| **再生リストの末尾** | 新しい動画を手動で末尾に追加している場合 |

非公開・削除済みの動画は自動的に除外されます。

### 使用例

```
🔥 {{title}}

▼ 最新のハイライトはこちら
{{playlist_highlight_url}}

#RIZIN
```

↓ 実際の投稿

```
🔥 【RIZIN】記者会見｜RIZIN.51

▼ 最新のハイライトはこちら
https://www.youtube.com/watch?v=xxxxxxxxx

#RIZIN
```

### リンクが取得できなかった場合

**コメントは投稿されません。** 「▼ 最新のハイライトはこちら」の後ろが空欄という
不自然なコメントが公開されるのを防ぐためです。

失敗すると通知が飛び、理由がログに残ります。よくある原因:

- YouTube が未連携
- 再生リストIDが間違っている
- 再生リストが非公開、または中身が空

なお取得結果は5分間キャッシュされます。再生リストに動画を追加した直後は、反映まで最大5分かかります。

## 文中のランダム置換

`[[A|B|C]]` と書くと、その部分だけが投稿ごとにランダムで変わります。

```
🔥 {{title}}
[[この一戦、何度でも見たい。|決着の瞬間をもう一度。|痺れる展開でした。]]

▼ 大会情報
https://jp.rizinff.com/
```

↓ 実際の投稿（毎回どれかが選ばれる）

```
🔥 【RIZIN】試合ハイライト｜〇〇 vs 〇〇
決着の瞬間をもう一度。

▼ 大会情報
https://jp.rizinff.com/
```

**文面まるごと**を変えたいときは「＋ 文面のバリエーションを追加」で複数登録、
**一部の言い回し**だけ変えたいときは `[[ ]]`、と使い分けてください。両方の併用もできます。

---

## プレビュー

編集画面の下にある **プレビュー** で、保存前に確認できます。

- 「テスト用の動画タイトル」に実際に来そうなタイトルを入れる
- **どのテンプレートが選ばれるか** と **実際に投稿される文面** が表示されます
- 編集中のテンプレートを開いている場合は、**未保存の内容**でプレビューされます

条件の出し分けが意図通りか、これで確認してから保存してください。

---

## 文字数の制限

| プラットフォーム | 上限 |
|---|---|
| YouTube | 9,000文字 |
| TikTok | 150文字 |

TikTokは短いので注意してください。超えた分は自動で切り詰められます（末尾が `…` になります）。
編集画面には文字数カウンタが出ます。

## 設定例

### 例1：試合の種類で文面を分ける

| 名前 | 優先度 | 条件 | 内容 |
|---|---|---|---|
| 記者会見用 | 10 | キーワード: `会見, 計量, 公開練習` | 大会告知メインの文面 |
| ハイライト用 | 20 | キーワード: `ハイライト, 全試合` | 感想を促す文面 |
| デフォルト | 999 | すべての動画 | 汎用の文面 |

「記者会見ダイジェスト」のように両方に当てはまるタイトルは、優先度10の会見用が使われます。

### 例2：YouTubeとTikTokで文面を変える

TikTokは150文字制限があり、URLも機能しないため、別テンプレートを用意します。

| 名前 | プラットフォーム | 内容 |
|---|---|---|
| YouTube用 | YouTubeのみ | 長文＋公式サイトURL |
| TikTok用 | TikTokのみ | 短文＋「プロフィールのリンクから」 |

### 例3：特定の大会だけ別文面

正規表現を使います。

```
条件: 正規表現
値:   RIZIN\.(5[0-9])
```

→ RIZIN.50〜RIZIN.59 のタイトルのときだけ、この文面を使う

## 投稿を一時的に止めたい

- **特定のテンプレートだけ止める** → そのテンプレートの「有効にする」をオフ
- **全部止める** → 環境変数 `DRY_RUN=true`（検知と文面生成だけ行い、投稿しません）

---

## 投稿履歴の確認

**「投稿履歴」** タブで、いつ・どの動画に・どのテンプレートで・何を投稿したかを確認できます。
コメント/ピン留めそれぞれの成否も分かります。
失敗しているものは **再実行** ボタンでやり直せます。
