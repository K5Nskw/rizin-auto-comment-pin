# 2. YouTube を連携する

YouTube は**新着検知とコメント投稿の両方を公式APIで行えます**。
（ピン留めだけは公式APIが無いため [Cookie登録](BROWSER-SESSION.md) が別途必要です）

## 2-1. Google Cloud プロジェクトを作る

1. https://console.cloud.google.com/ を開く
2. 上部のプロジェクト選択 → **新しいプロジェクト** → 名前を付けて作成

## 2-2. YouTube Data API v3 を有効化する

1. **APIとサービス** → **ライブラリ**
2. 「YouTube Data API v3」を検索 → **有効にする**

## 2-3. OAuth 同意画面を設定する

1. **APIとサービス** → **OAuth同意画面**
2. User Type: **外部** を選択（Google Workspace なら「内部」でも可）
3. アプリ名・サポートメール・デベロッパー連絡先を入力
4. **スコープ** で以下を追加：
   ```
   https://www.googleapis.com/auth/youtube.force-ssl
   ```
   > このスコープがコメント投稿に必要です。読み取り専用スコープでは投稿できません。
5. **テストユーザー** に、RIZINのYouTubeチャンネルを管理している Google アカウントを追加

> **重要**：公開ステータスが「テスト」のままだと、**リフレッシュトークンが7日で失効**します。
> 7日ごとに再連携するのが面倒な場合は、同意画面を **「本番環境」に公開** してください。
> 自分のチャンネルにしかアクセスしない用途なので、審査なしで公開状態にできます
> （機密スコープを含むため警告画面は出ますが、「詳細」→「安全でないページに移動」で進めます）。

## 2-4. OAuth クライアントIDを作る

1. **APIとサービス** → **認証情報** → **認証情報を作成** → **OAuthクライアントID**
2. アプリケーションの種類: **ウェブアプリケーション**
3. **承認済みのリダイレクトURI** に以下を追加：
   ```
   https://<Railwayで発行したURL>/oauth/youtube/callback
   ```
   例: `https://rizin-auto-comment-pin-production.up.railway.app/oauth/youtube/callback`
4. 作成すると **クライアントID** と **クライアントシークレット** が表示されます

## 2-5. Railway に設定する

Railway の Variables に追加：

```
YOUTUBE_CLIENT_ID=<クライアントID>
YOUTUBE_CLIENT_SECRET=<クライアントシークレット>
```

保存すると自動で再デプロイされます。

## 2-6. 連携する

1. 管理画面 → **アカウント連携** タブ
2. **YouTube を連携する** をクリック
3. RIZINチャンネルを管理している Google アカウントでログイン → 権限を許可
4. 「YouTube を連携しました」と表示されればOK

ダッシュボードの YouTube カードに、チャンネル名と「即時通知: 有効」が表示されます。

## 2-7. 即時通知（push通知）について

このツールは YouTube の **WebSub (PubSubHubbub)** を使って、
動画が公開された瞬間に通知を受け取ります（ポーリング待ちが不要）。

- 連携時に自動で購読します
- 購読の有効期限は5日で、6時間ごとに自動更新されます
- ダッシュボードで「即時通知: 無効」になっていたら、
  **アカウント連携** タブの「YouTube 即時通知を再購読」を押してください

push通知が使えない場合も、`POLL_INTERVAL_MINUTES` ごとのRSSポーリングで検知されます（最大数分の遅れ）。

## 補足：別チャンネルを監視したい場合

連携したアカウントのチャンネルではなく、特定のチャンネルを監視したい場合は
環境変数 `YOUTUBE_CHANNEL_ID` に `UC` から始まるチャンネルIDを設定してください。
（ただしコメント投稿は連携したアカウントの名義で行われます）

## APIの消費量について

YouTube Data API の1日の上限は既定10,000ユニットです。

| 操作 | 消費 |
|---|---|
| RSSでの新着チェック | 0（APIを使わないため） |
| 動画の公開状態の確認 | 1 |
| コメント投稿 | 50 |

1日に数十本投稿しても上限には届きません。
