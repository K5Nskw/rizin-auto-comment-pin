# AutoClipMaker 連携

[AutoClipMaker](https://github.com/K5Nskw/AutoClipMaker) が切り抜きを投稿すると、
このツールに通知が届き、以下を自動で行います。

1. **Shorts の「関連動画」に元動画を設定**（非公開のままでも実行されます）
2. コメントを投稿してピン留め（公開後）

元動画は AutoClipMaker から直接送られてくるので、タイトルから推測することはありません。

## つなぎ方

### ① このツール側

Railway の Variables に共有トークンを設定します。

```
INGEST_TOKEN=<openssl rand -hex 32 の出力>
```

### ② AutoClipMaker 側

Railway の Variables に2つ設定します。

```
COMMENT_HOOK_URL=https://<このアプリのURL>/ingest/clip
COMMENT_HOOK_TOKEN=<上の INGEST_TOKEN と同じ値>
```

URL は管理画面のダッシュボード「各コンソールに登録するURL」からコピーできます。

## 動作

```
AutoClipMaker が切り抜きを投稿
        ↓  POST /ingest/clip
   切り抜きのURL・タイトル・元動画のURL・元動画のタイトル・切り出し位置
        ↓
① 関連動画を元動画に設定   ← 非公開でも実行
        ↓
② 公開されたらコメント投稿 → ピン留め
```

**関連動画の設定はコメントより先に行われます。** 非公開のうちにリンクを張っておけるので、
公開された瞬間から本編への導線が効きます。コメントは公開されるまで待機します。

## コメントの文面について

**切り抜き専用のテンプレートはありません。** Shorts も通常の動画も、
条件に一致した同じテンプレートが使われます。文面を変えたい場合は
「コメント文の編集」タブで、対象プラットフォームや条件を設定してください。

## 管理画面での確認

**アカウント連携**タブの「2. AutoClipMaker 連携」に、受け口が有効か（`INGEST_TOKEN` が設定済みか）と、
関連動画の設定が実行可能か（ブラウザ自動操作が使えるか）が表示されます。
AutoClipMaker に設定する `COMMENT_HOOK_URL` もここからコピーできます。

**投稿履歴**タブには **「関連動画」列** があります。

| 表示 | 意味 |
|---|---|
| 設定済み | 元動画へのリンクが設定されました |
| 未設定 | まだ設定されていません（実行待ち、または失敗） |
| 対象外 | 切り抜きではない動画（元動画の情報がありません） |

元動画のタイトルがリンクとして表示されるので、どの動画に紐づいたかがその場で分かります。
失敗した場合は **「関連動画を再設定」** ボタンで、その手順だけをやり直せます
（「再実行」はジョブ全体をやり直すため、コメント投稿済みの場合はこちらを使ってください）。

## 制約

| 項目 | 状況 |
|---|---|
| 関連動画の設定API | **存在しません**。YouTube Studio の画面自動操作で実現しています |
| 必要なもの | ピン留めと同じ Cookie（「アカウント連携」タブで登録） |
| 壊れやすさ | Studio の画面変更で動かなくなる可能性があります。失敗時はログとスクリーンショットに理由が残ります |

## 二重投稿について

同じ切り抜きを何度送っても、コメントは1回しか付きません。1動画につきジョブは1件しか作られず、
これはデータベースの制約で保証されています。AutoClipMaker 側の「コメント連携を再送」も安全に使えます。

## うまくいかないとき

| 症状 | 原因 |
|---|---|
| AutoClipMaker に「トークンが一致しません」と出る | `INGEST_TOKEN` と `COMMENT_HOOK_TOKEN` が違います |
| 「連携先に接続できませんでした」 | `COMMENT_HOOK_URL` が違うか、このアプリが停止しています |
| 関連動画が設定されない | 下の「関連動画が付かないとき」を参照してください |
| コメントが付かない | 切り抜きが非公開のままだと、公開されるまで待機します（関連動画は設定済みのはずです） |

## 関連動画が付かないとき

投稿履歴の **関連動画** の欄で状態が分かります。

| 表示 | 意味 |
|---|---|
| 設定済み | 元動画へのリンクが張られています |
| 未設定 | まだ張られていません（下記の順に確認してください） |
| 対象外 | AutoClipMaker 経由ではない動画です。元動画が分からないので何もしません |

**「未設定」のときは、その下に理由が出ます。** よくあるのは次の3つです。

| 出ている理由 | 直し方 |
|---|---|
| ブラウザ自動操作が使えません | Chromium が無いか `ENABLE_BROWSER_AUTOMATION=false` です |
| ログイン画面に転送されました | Cookie が失効しています。「アカウント連携」タブで登録し直してください |
| 「関連動画」の設定欄が見つかりませんでした | ショートではない動画か、Studio の画面が変わっています |

**関連動画が失敗しても、コメントの投稿は止まりません。** Studio の画面操作は
UIの変更やCookieの失効で落ちうるので、ここで止めるとリンクが張れないだけでなく
コメントまで出なくなってしまいます。理由を残して先へ進み、
投稿履歴の **「関連動画を再設定」** で個別にやり直せます。

**「未設定」のときに見るところ**

1. **元動画の情報が届いているか** — 「対象外」と出ているなら届いていません。
   AutoClipMaker 側の各切り抜きの **「コメント連携を再送」** を押してください
2. **ブラウザ自動操作が使えるか** — 関連動画にAPIは無く、Studio の画面操作で設定します。
   ピン留めと同じ Cookie が要ります。「アカウント連携」タブで **ログイン確認** を押してください
3. **その場でやり直す** — 投稿履歴の **「関連動画を設定」** で、その1件だけ実行し直せます

理由はログタブに残ります。Cookie が無い状態で飛ばされた場合も、その旨が記録されます。

### 連携より後に気づいた場合

**ジョブは動画1本につき1件しか作りません。** そのため、切り抜きだと分かる前に
ジョブができていると（新着検知が先に拾った、連携を入れる前に投稿した）、
関連動画の設定が入らないままになります。

この場合は AutoClipMaker 側の **「コメント連携を再送」** を押してください。
既にあるジョブに関連動画の設定だけを足して、もう一度実行します。
コメントは済みフラグで守られているので、二重に投稿されることはありません。
